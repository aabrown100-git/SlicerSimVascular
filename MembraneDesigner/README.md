# Membrane Designer

Membrane Designer is an experimental 3D Slicer module for designing a flat membrane pattern and previewing the pressurized 3D membrane obtained after sewing its boundary to a fixed spatial contour.

The current implementation establishes the Slicer user interface, persistent data model, boundary correspondence, strain visualization, and a CPU-compatible XPBD preview solver. It is an implementation scaffold for the planned Taichi DiffXPBD forward and inverse-design system; it is not yet a validated tissue-mechanics solver.

## Current workflow

1. Open **Membrane Designer** from Slicer's module selector.
2. Select a `vtkMRMLMarkupsClosedCurveNode` as the suture contour, or click **Create demo seam**.
3. Edit the flat periodic spline using the draggable control points in the **Flat pattern (2D)** dock on the right.
4. Set pressure, Young's modulus, thickness, and damping.
5. Click **Simulate**, or pause after editing to trigger the debounced preview.
6. Inspect the inflated membrane in the 3D views and select maximum principal strain, areal strain, or correspondence-only coloring.

The 2D pattern and 3D seam share a cyclic normalized-arclength color map. The large black-and-white marker identifies the start of the correspondence, preventing ambiguity where the cyclic color map wraps.

## Implemented features

### Slicer integration

- Scripted loadable module registered by the parent `SlicerSimVascular` extension.
- Qt Designer `.ui` file for the module control panel.
- `parameterNodeWrapper` model that persists:
  - Suture-curve and output-model references.
  - Pressure and material settings.
  - Damping and visualization selection.
  - Serialized 2D spline control points.
- Scene-close/reload handling and source-tree loading through Extension Wizard.
- Dedicated right-side Qt graphics dock for the flat-pattern editor.

### Pattern and correspondence

- Periodic uniform cubic B-spline boundary.
- Draggable 2D control points with debounced simulation updates.
- Initial 2D control polygon generated by projecting uniformly sampled seam
  points onto the seam's PCA best-fit plane.
- Constrained unstructured triangular mesh with deterministic jittered interior
  sampling and an explicitly preserved, ordered boundary.
- Normalized-arclength sampling of the Slicer closed curve.
- Matching cyclic colors on the flat boundary and 3D seam.
- Direct RGB display of seam correspondence colors to avoid lookup-table
  remapping and repeated color regions.
- Persistent `BoundaryArclength` point-data array on the output mesh.

### Forward preview

- Separate 2D rest coordinates and 3D simulated coordinates.
- Seam-aware affine initialization of the interior surface.
- Hard positional constraints on boundary particles.
- Uniform pressure continuation.
- Lumped vertex masses computed from rest area, thickness, and a tissue-like
  density of 1000 kg/m³, represented in the solver's mm–N–s unit system.
- Explicit pressure conversion from kPa to N/mm².
- A 0.1 ms integration timestep, with timestep-independent damping conversion,
  to resolve the elastic timescale after replacing the former unit masses.
- Vectorized damped Jacobi XPBD edge-length projection.
- CPU-compatible NumPy implementation suitable for functional testing.
- Stable planar ellipse demonstration case.

### Strain output

- Per-triangle deformation gradient from the 2D rest triangle to the current 3D triangle.
- Green-Lagrange strain tensor evaluation.
- Maximum principal strain and areal strain cell-data arrays.
- Slicer scalar coloring using cell data.
- Preview status reporting with mesh size, step count, and maximum principal strain.

## Testing

Run the core test using Slicer's Python environment:

```bash
"/Applications/Slicer 2.app/Contents/MacOS/Slicer" \
  --no-main-window \
  --disable-cli-modules \
  --python-code "import sys; sys.path.insert(0, '/path/to/SlicerSimVascular/MembraneDesigner'); import MembraneDesigner; MembraneDesigner.MembraneDesignerTest().runTest(); print('MEMBRANE_TEST_OK'); slicer.app.exit(0)"
```

The current test verifies mesh dimensions, finite positions and strains, and exact enforcement of the sewn boundary. Development checks should also include:

```bash
python3 -m py_compile MembraneDesigner/MembraneDesigner.py
xmllint --noout MembraneDesigner/Resources/UI/MembraneDesigner.ui
git diff --check
```

The module has been loaded through Extension Wizard and exercised interactively in Slicer 5.10 on macOS.

## Current limitations

- The solver uses edge-length constraints, not the planned triangle Green-strain DiffXPBD formulation.
- The numerical conversion from physical material values to XPBD compliance is provisional and uncalibrated.
- Strain values are engineering diagnostics only and must not be interpreted as validated tissue stresses or failure predictions.
- Pressure scaling is currently a preview-scale numerical conversion rather than a fully unit-consistent membrane load.
- There is no shear/area constraint, bending constraint, contact, friction, self-collision, or triangle-inversion barrier.
- Nonplanar and excess-material seams may wrinkle, fold, or converge to an unintended branch.
- The solve runs synchronously on the UI thread; cancellation, streamed previews, and stale-result rejection are not implemented.
- Taichi, GPU execution, analytical adjoints, and gradient checks are not implemented.
- Seam start/direction landmarks, SVG import/export, hover-linked correspondence, and color legends remain incomplete.

## Next steps

### 1. Harden the existing preview

- Split geometry, solver, visualization, and widget code into testable modules.
- Add element-quality checks, orientation validation, and clear failure states.
- Add triangle inversion detection and refuse to report strain on invalid elements.
- Expose timestep, iteration count, convergence tolerances, and pressure stages under advanced controls.
- Replace the fixed step count with velocity, residual, and position-change convergence tests.
- Run solves in a cancellable worker and update MRML nodes only on the main thread.
- Add a scalar legend, fixed/automatic strain ranges, percentile statistics, and signed tension/compression coloring.
- Add explicit start and direction landmarks and hover-linked 2D/3D correspondence.

### 2. Implement the Taichi forward solver

- Move positions, velocities, masses, triangles, constraints, and multipliers into Taichi fields.
- Support Metal and CUDA with a deterministic CPU fallback.
- Implement per-triangle Green-strain constraints for stretch and shear.
- Convert Young's modulus, Poisson ratio, thickness, and rest area into a consistent plane-stress constitutive model and XPBD compliance.
- Add weak hinge-based bending regularization.
- Implement unit-consistent pressure forces from oriented current triangle areas.
- Add zero-pressure relaxation followed by pressure continuation.
- Validate circular and elliptical bulge cases under timestep, iteration, and mesh refinement.

### 3. Add differentiable DiffXPBD

- Implement the DiffXPBD analytical/adjoint backward pass instead of storing a completely unrolled autodiff tape.
- Expose derivatives with respect to 2D rest vertex coordinates.
- Differentiate through periodic spline evaluation and interior rest-mesh deformation to the spline control points.
- Compare gradients with central finite differences on small meshes.
- Detect discontinuities caused by inversion, contact, or equilibrium-branch changes and report invalid gradients.

### 4. Generalize the pattern mesh

- Add mesh-quality controls and local refinement for constrained triangulation.
- Preserve topology during control-point optimization using harmonic interior deformation.
- Add self-intersection, minimum-angle, minimum-area, and conditioning checks.
- Support controlled remeshing outside differentiable optimization steps, with state transfer and explicit gradient invalidation.
- Add SVG and point-loop import plus SVG/reference-mesh export.

### 5. Add inverse shape optimization

- Define a solver-facing loss API independently of the Slicer UI.
- Start with a synthetic registered-surface loss to validate end-to-end spline gradients.
- Add Adam or L-BFGS optimization over the spline controls with smoothness and deviation regularization.
- Persist optimization history, loss components, accepted/rejected updates, and intermediate patterns.
- Add fixed-centerline cross-sectional-area constraints only after the differentiable surface pipeline is validated.
- Keep VMTK centerline generation outside the differentiable loop; use fixed section planes during each optimization run.

### 6. Validation and release readiness

- Calibrate material parameters against membrane inflation experiments or trusted finite-element results.
- Establish unit conventions and document every conversion.
- Add CPU/GPU regression tolerances and performance benchmarks near the 2,000-vertex target.
- Add scene save/reload tests covering all parameter-node fields and node references.
- Add representative nonplanar anatomical seams and quantify convergence, mesh validity, and strain stability.
- Document clinical-use limitations before distributing the module beyond research development.

## Recommended immediate milestone

The next implementation milestone should be a unit-consistent Taichi forward solver with triangle Green-strain constraints, inversion detection, and convergence-based stopping. It should reproduce the current planar demo, pass refinement studies, and generate trustworthy strain fields before work begins on analytical gradients or inverse optimization.
